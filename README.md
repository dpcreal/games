# Unstoppable Games

A static Vercel arcade where every tile opens a locally hosted game page. The site does not use iframes or external game embeds.

## Games

- Slope, restored as a full local Unity WebGL build.
- Snow Rider 3D, restored as a full local Unity WebGL build.
- Snake, Breakout, Memory Match, and Block Dodge, included as self-contained browser games.

## Deploying on Vercel

Import `dpcreal/games` into Vercel as a static project. There is no build command and the output directory is the repository root.
